# Final QA Checklist for ACVRP-CO2 Repository

Use this checklist before making the repository public or using it as supplementary material.

## Code and environment

- [ ] `requirements.txt` is present and up to date.
- [ ] `environment.yml` is present if Conda is recommended.
- [ ] Python version is documented.
- [ ] No absolute local paths are hard-coded.
- [ ] Scripts can be run from the repository root.
- [ ] CLI scripts have useful error messages.
- [ ] Dry-run options work for expensive experiments.
- [ ] `pytest -q` passes, or failures are documented.

## Data and graph files

- [ ] Fixed customer CSV files are present or documented.
- [ ] Randomized instance CSV files are generated by code.
- [ ] GraphML files are present under `graphs/` or linked in README.
- [ ] OSM extraction settings are documented.
- [ ] OpenStreetMap attribution is included where needed.
- [ ] Large files are not accidentally committed.

## Randomized experiment

- [ ] `configs/randomized.yaml` exists.
- [ ] Random seed is fixed.
- [ ] Number of instances per city is documented.
- [ ] Number of customers per instance is documented.
- [ ] Vehicle capacity and number of vehicles are documented.
- [ ] Demand generation rule is documented.
- [ ] Candidate customer nodes are reachable from depot and back to depot.
- [ ] Raw results contain SE, SM, SR, and AR rows for each successful instance.
- [ ] AR is used as the reference variant.
- [ ] Penalties are computed from AR-evaluated metrics.
- [ ] Failed or infeasible runs are recorded.

## Result files

- [ ] `results/randomized/raw_results.csv` exists.
- [ ] `results/randomized/penalty_summary.csv` exists.
- [ ] `results/randomized/statistical_tests.csv` exists or absence is explained.
- [ ] `manuscript/tables/randomized_results.tex` exists.
- [ ] CSV schemas are documented in README.
- [ ] Results can be regenerated from scripts.

## Figures

- [ ] `figures/fig1_pipeline.pdf` and `.png` exist.
- [ ] `figures/fig2_fixed_penalty.pdf` and `.png` exist.
- [ ] `figures/fig3_randomized_boxplot.pdf` and `.png` exist.
- [ ] `figures/fig4_solver_heatmap.pdf` and `.png` exist.
- [ ] Figures use readable font sizes.
- [ ] Figures are generated from saved data files.
- [ ] Figure captions in the manuscript can be written based on generated outputs.

## Documentation

- [ ] README explains the research question.
- [ ] README explains the repository structure.
- [ ] README contains exact reproduction commands.
- [ ] README lists expected outputs.
- [ ] README documents data sources and graph cache files.
- [ ] README does not claim publication before acceptance.
- [ ] README includes known limitations.
- [ ] License is included or clearly marked as TODO.

## Manuscript support files only

The manuscript is maintained in Overleaf, so the repository should provide support files rather than directly editing Overleaf content.

- [ ] Manuscript-ready tables are under `manuscript/tables/`.
- [ ] Manuscript figures are under `figures/`.
- [ ] No unnecessary edits were made to `manuscript/main.tex`.
- [ ] Data and Code Availability can reference the final public repository URL.

## Claim safety

Generated documentation should avoid overclaiming.

- [ ] No claim says the findings are universal.
- [ ] No claim says neural solvers are superior unless supported by results.
- [ ] Randomized results are described as robustness evidence, not proof.
- [ ] Limitations mention two cities, synthetic demand, and simplified emissions.

## Release readiness

- [ ] Repository can be cloned and used by a new user.
- [ ] Main commands have been tested on a clean environment or documented.
- [ ] Public repository URL is ready for the manuscript.
- [ ] Large artifacts are stored appropriately.
- [ ] Final QA report has no unresolved critical failures.
